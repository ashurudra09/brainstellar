## Question
Given f(x) = 1 + 2^x·log2 (garbled) equals d/dx G(x), and G(2) = 8, find G(3).

## Options

- 11
- 13
- 15

## Answer
**C.** 13

## Solution
Then G = x + 2ˣ + C. G(2) = 6 + C = 8 gives C = 2, so G(3) = 3 + 8 + 2. The source expression is garbled, so this reads it the most likely way.
