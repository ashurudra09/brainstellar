## Question
For a 4-class softmax output, which is always true?

## Options
- Each value in (0,1) and they sum to 1
- Values can be negative
- Sum can exceed 1
- Only for binary

## Answer
**A.** Each value in (0,1) and they sum to 1

## Solution
Softmax exponentiates (positive) and normalises.
