## Question
In reinforcement learning, what does a policy define?

## Options
- Environment state
- Reward structure
- Probability distribution over actions given a state
- Discount factor

## Answer
**C.** Probability distribution over actions given a state

## Solution
π(a\|s). The reward structure and discount factor belong to the environment / problem definition.
