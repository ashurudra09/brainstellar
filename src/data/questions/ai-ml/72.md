## Question
Which regularisation drives some weights to exactly zero?

## Options
- L2 (Ridge)
- L1 (Lasso)
- Dropout
- Batch norm

## Answer
**B.** L1 (Lasso)

## Solution
L1 adds λ·Σ\|w\|, a constant-strength pull toward zero, so weak weights land exactly at 0 (automatic feature selection). L2's pull weakens as w shrinks, so weights get small but rarely reach zero.
