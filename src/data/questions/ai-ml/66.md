## Question
Time complexity of full self-attention over a sequence of length n with model width d?

## Options
- O(n²·d)
- O(n·d²) only
- O(n log n)
- O(n)

## Answer
**A.** O(n²·d)

## Solution
QKᵀ is n × n, and each entry is a d-length dot product. The feed-forward layers add O(n·d²).
