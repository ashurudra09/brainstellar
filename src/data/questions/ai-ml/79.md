## Question
Which is a case of data leakage?

## Options
- Using k-fold CV
- Fitting a StandardScaler on the full dataset before splitting
- Using a validation set
- Shuffling the training data

## Answer
**B.** Fitting a StandardScaler on the full dataset before splitting

## Solution
The scaler's mean and standard deviation then include the test rows, so test information leaks into training and the score is over-optimistic. Fit on the training split only, then transform the test split.
