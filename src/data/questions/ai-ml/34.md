## Question
For f(x) = x^4 − 4x^3 + 5, what kind of critical point is x = 3?

## Options
- Inflection point
- No critical point
- Local minimum
- Local maximum

## Answer
**C.** Local minimum

## Solution
f′ = 4x²(x − 3) = 0 at x = 3, and f″(3) = 108 − 72 = 36 \> 0.
