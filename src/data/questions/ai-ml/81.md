## Question
A is 3×4 and B is 4×2. Which products are defined?

## Options
- AB only
- BA only
- Both
- Neither

## Answer
**A.** AB only

## Solution
AB: (3×4)(4×2), the inner dimensions match (4 = 4), so the result is 3×2. BA: (4×2)(3×4), and 2 ≠ 3, so it is undefined.
