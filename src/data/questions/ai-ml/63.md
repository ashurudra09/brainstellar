## Question
Input 32×32×3, 16 filters of 5×5, stride 1, no padding. Output volume?

## Options
- 32×32×16
- 28×28×16
- 28×28×3
- 16×16×16

## Answer
**B.** 28×28×16

## Solution
(32 − 5 + 0)/1 + 1 = 28; the depth equals the number of filters.
