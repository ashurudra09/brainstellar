## Question
Key assumption of Naive Bayes?

## Options
- Features correlated
- Features conditionally independent given class
- Uniform data
- Linear boundary

## Answer
**B.** Features conditionally independent given class

## Solution
This lets P(x\|y) factor into a product of per-feature terms.
