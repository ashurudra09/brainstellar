## Question
The target variable was accidentally included among scaled features. What happens?

## Options
- PCA applied incorrectly
- Model generalises exceptionally well
- Test set corrupted
- Data leakage inflates performance

## Answer
**D.** Data leakage inflates performance

## Solution
The model can read the answer straight from its inputs. Validation scores look great, then it fails in production.
