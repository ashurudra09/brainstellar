## Question
Contrast L1 and L2 regularisation.

## Options
- L1 sparse, L2 spreads weights
- Reverse
- Both sparse
- Neither affects selection

## Answer
**A.** L1 sparse, L2 spreads weights

## Solution
L1's corner at 0 pushes weights exactly to zero, so it also selects features.
