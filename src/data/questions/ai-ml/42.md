## Question
How many solutions: 2x+y−z=4, x−2y+z=−2, −x+2y−z=−2?

## Options
- 0
- 1
- Infinite
- Cannot be determined

## Answer
**A.** 0

## Solution
Adding equations 2 and 3 gives 0 = −4, so the system is inconsistent.
