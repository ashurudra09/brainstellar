## Question
Eigenvalues of the 4×4 matrix with 0 on the diagonal and 1 everywhere else?

## Options
- 2,−2,0,0
- 1,−1,1,−1
- 3,−1,−1,−1
- 4,0,0,0

## Answer
**C.** 3,−1,−1,−1

## Solution
The matrix is J − I. J (all ones) has eigenvalues 4, 0, 0, 0, so subtract 1 from each.
