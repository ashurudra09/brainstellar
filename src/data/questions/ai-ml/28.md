## Question
Which problem is batch normalization commonly used to address?

## Options
- Internal covariate shift
- Vanishing gradients
- Underfitting
- Overfitting from large weights

## Answer
**A.** Internal covariate shift

## Solution
This is the original motivation given for batch norm: it stabilises each layer's input distribution. Faster training and some regularisation are side effects.
