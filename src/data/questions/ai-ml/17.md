## Question
Which converges faster per update: stochastic gradient descent or batch gradient descent?

## Answer
SGD makes faster progress per unit of compute, but noisily; batch GD takes smooth, expensive steps

## Solution
Each SGD update uses one sample, so you get many cheap updates per epoch.
