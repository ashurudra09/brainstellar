## Question
Group a large set of cosmetic products into categories by similarity with no labels or prior info. Best algorithm?

## Options
- Decision tree
- Logistic regression
- K-means clustering
- Linear regression

## Answer
**C.** K-means clustering

## Solution
There are no labels, so this is unsupervised. The other three options are supervised.
