## Question
LoRA fine-tuning:

## Options
- Freezes the base weights and trains low-rank update matrices
- Retrains every weight in lower precision
- Removes attention heads
- Only tunes the tokenizer

## Answer
**A.** Freezes the base weights and trains low-rank update matrices

## Solution
W + BA with rank r ≪ d, so far fewer trainable parameters. QLoRA does the same on a 4-bit quantised base.
