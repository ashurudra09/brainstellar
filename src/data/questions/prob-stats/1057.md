## Question
Var(X)=1, Var(Y)=4, Var(2X−3Y)=34. Find corr(X,Y).

## Options
- 1/2
- 1/4
- 1/3
- None of these

## Answer
**B.** 1/4

## Solution
Var(2X − 3Y) = 4·1 + 9·4 − 12·Cov = 34, so Cov = 0.5 and corr = 0.5/(1·2).
