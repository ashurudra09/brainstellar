## Question
Which option best describes Bayesian inference in ML?

## Options
- Estimating parameters by maximum likelihood
- Minimising hinge loss
- Updating prior beliefs with observed data via Bayes' theorem
- Gradient descent on probability distributions

## Answer
**C.** Updating prior beliefs with observed data via Bayes' theorem

## Solution
MLE ignores the prior; hinge loss and gradient descent are unrelated.
