## Question
X takes 0,1,2,3 with probabilities 0.1, 0.2, 0.3, 0.4. Find Var(X).

## Options
- \0.9
- \0.8
- \1.0
- \1.1

## Answer
**C.** \1.0

## Solution
E\[X\] = 2.0, E\[X²\] = 0.2 + 1.2 + 3.6 = 5.0, so Var = 5 − 4 = 1.
