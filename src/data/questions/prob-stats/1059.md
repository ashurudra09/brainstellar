## Question
For a medical screening test where false negatives must be minimised, how should the p-value threshold be chosen?

## Options
- Higher
- Lower
- Same
- False negatives don't depend on p-value

## Answer
**A.** Higher

## Solution
A higher α threshold rejects H₀ more easily. That means more positives flagged and fewer missed: fewer false negatives, at the cost of more false positives.
