## Question
In logistic classification, what is the upper bound of the likelihood and is it attainable?

## Options
- 1, No
- e, No
- 1, Yes
- 0, Yes

## Answer
**A.** 1, No

## Solution
Each sigmoid output is strictly between 0 and 1, so the product of probabilities approaches 1 but never reaches it (only as weights go to infinity on separable data).
