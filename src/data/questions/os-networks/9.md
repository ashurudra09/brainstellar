## Question
Which page-replacement algorithm can suffer from Belady's anomaly?

## Options
- LRU (least recently used)
- Optimal
- FIFO (first in, first out)
- LFU with aging

## Answer
**C.** FIFO (first in, first out)

## Solution
Under FIFO, adding frames can increase page faults. LRU and Optimal are 'stack algorithms': the pages kept with n frames are always a subset of those kept with n + 1, so more frames can never hurt.
