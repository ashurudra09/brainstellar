## Question
Number of usable host addresses in a /26 subnet?

## Options
- 64
- 62
- 30
- 126

## Answer
**B.** 62

## Solution
32 − 26 = 6 host bits gives 2⁶ = 64 addresses. Subtract the network address (host bits all 0) and the broadcast address (all 1) to get 62.
