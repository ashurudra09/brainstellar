## Question
How many processes in total?

```text
if (fork() && fork())
    fork();
```

## Options
- 3
- 4
- 5
- 8

## Answer
**B.** 4

## Solution
fork returns 0 in the child. The first child sees 0, so && short-circuits and it stops. The parent runs the second fork, and that child also sees 0 and stops. Only the parent enters the body and forks a third child. Parent + 3 children = 4.
