## Question
TLB access 10 ns, memory access 100 ns, TLB hit ratio 0.9 (single-level paging). Effective access time?

## Options
- 110 ns
- 120 ns
- 130 ns
- 200 ns

## Answer
**B.** 120 ns

## Solution
Hit: TLB + data = 10 + 100 = 110. Miss: TLB + page table + data = 10 + 100 + 100 = 210. EAT = 0.9 × 110 + 0.1 × 210 = 99 + 21 = 120 ns.
