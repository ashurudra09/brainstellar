## Question
Which HTTP method is NOT idempotent?

## Options
- GET
- PUT
- DELETE
- POST

## Answer
**D.** POST

## Solution
Idempotent means repeating the request has the same effect as sending it once. Repeating a POST can create a second resource, such as a duplicate order. PUT sets a fixed value, and DELETE on something already deleted changes nothing.
