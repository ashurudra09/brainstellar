## Question
At which OSI layer does a router operate?

## Options
- Data link (2)
- Network (3)
- Transport (4)
- Physical (1)

## Answer
**B.** Network (3)

## Solution
A router forwards packets between networks using IP addresses, which is the network layer. A switch forwards frames within one network using MAC addresses (layer 2).
