## Question
Go-Back-N with 3-bit sequence numbers. Maximum sender window?

## Options
- 3
- 4
- 7
- 8

## Answer
**C.** 7

## Solution
3 bits give 8 sequence numbers. Go-Back-N allows 2ᵏ − 1 = 7. With 8, if every acknowledgement were lost the receiver couldn't tell a new frame 0 from a resent old one. Selective Repeat allows 2ᵏ⁻¹ = 4.
