## Question
A zombie process is one that:

## Options
- Has lost its parent
- Has terminated but whose parent hasn't called wait()
- Is stuck in an infinite loop
- Is swapped out to disk

## Answer
**B.** Has terminated but whose parent hasn't called wait()

## Solution
Its process-table entry stays so the parent can read the exit status with wait(). A process whose parent died first is an orphan, which init adopts.
