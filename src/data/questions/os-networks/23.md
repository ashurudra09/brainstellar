## Question
ARP (Address Resolution Protocol) resolves:

## Options
- Domain name to IP
- IP to MAC
- MAC to IP
- Port to process

## Answer
**B.** IP to MAC

## Solution
A host knows the local IP it wants to reach and broadcasts 'who has this IP?' to learn the hardware (MAC) address. DNS does name → IP.
