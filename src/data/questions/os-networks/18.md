## Question
Fastest form of inter-process communication (IPC)?

## Options
- Pipes
- Message queues
- Shared memory
- Sockets

## Answer
**C.** Shared memory

## Solution
Both processes map the same physical memory, so after setup no data passes through the kernel. The price is that you must synchronise access yourself, for example with semaphores.
