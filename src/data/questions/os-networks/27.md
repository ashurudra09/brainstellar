## Question
HTTP/3 runs on top of:

## Options
- TCP
- QUIC over UDP
- SCTP
- Raw IP

## Answer
**B.** QUIC over UDP

## Solution
QUIC is a transport protocol built on UDP with encryption included. A lost packet only stalls its own stream, unlike HTTP/2 over TCP, where one loss stalls everything.
