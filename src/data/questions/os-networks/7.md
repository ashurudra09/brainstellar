## Question
How many processes exist in total (including the parent) after this runs?

```text
fork();
fork();
fork();
```

## Options
- 3
- 6
- 7
- 8

## Answer
**D.** 8

## Solution
Each fork is run by every process that exists at that moment, so the count doubles each time: 1 → 2 → 4 → 8. That's 2³ = 8 processes, 7 of them children.
