## Question
Output?

```c
void swap(int a, int b) { int t = a; a = b; b = t; }
int main() {
    int x = 1, y = 2;
    swap(x, y);
    printf("%d %d", x, y);
}
```

## Options
- 1 2
- 2 1
- Garbage
- Compile error

## Answer
**A.** 1 2

## Solution
C passes by value, so swap changes only its own copies. To swap the originals, pass pointers: swap(&x, &y).
