## Question
Output?

```python
x = 10
def h():
    x += 1
    return x
h()
```

## Options
- UnboundLocalError
- 11
- 10
- None

## Answer
**A.** UnboundLocalError

## Solution
Assigning to x anywhere in a function makes x local to the whole function, so x += 1 reads a local before it has a value. Declare global x to fix it.
