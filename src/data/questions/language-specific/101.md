## Question
Output?

```python
print(0 or "x", 3 and 4, bool([0]), bool(" "))
```

## Options
- x 4 True True
- x 3 False True
- True True True True
- x 4 False False

## Answer
**A.** x 4 True True

## Solution
or returns the first truthy operand; and returns the last operand if all are truthy. A non-empty list or string is truthy, even \[0\].
