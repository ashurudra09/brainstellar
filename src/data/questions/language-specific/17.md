## Question
Output?

```c
float x = 7 / 2;
printf("%.1f", x);
```

## Options
- \3.0
- \3.5
- \4.0
- 3

## Answer
**A.** \3.0

## Solution
7/2 is integer division (3), done before the conversion to float. Use 7/2.0 to get 3.5.
