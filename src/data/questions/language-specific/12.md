## Question
Why must a C++ copy constructor take its argument by reference?

## Options
- Performance only
- Passing by value would call the copy constructor recursively
- Required for const-correctness
- Templates need it

## Answer
**B.** Passing by value would call the copy constructor recursively

## Solution
Passing by value means making a copy of the argument, which calls the copy constructor, which needs another copy… infinite recursion. A reference passes the object without copying it.
