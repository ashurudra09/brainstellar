## Question
Output?

```c
int i;
for (i = 0; i < 5; i++);
printf("%d", i);
```

## Options
- 5
- 0 1 2 3 4
- 4
- Infinite loop

## Answer
**A.** 5

## Solution
The stray ; is the loop's (empty) body. printf runs once, after the loop, when i = 5.
