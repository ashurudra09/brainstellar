## Question
Output?

```c
enum { A, B = 5, C };
printf("%d %d", A, C);
```

## Options
- 0 6
- 0 2
- 1 6
- 0 5

## Answer
**A.** 0 6

## Solution
Enum values start at 0 and each one continues from the previous value: A = 0, B = 5, C = 6.
