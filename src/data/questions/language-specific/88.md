## Question
What happens?

```java
class Pv { private int v; }
class Use { int read(Pv p) { return p.v; } }
```

## Options
- Compile error: v has private access
- Returns 0
- Runtime IllegalAccessError
- Returns null

## Answer
**A.** Compile error: v has private access

## Solution
private means visible only inside Pv itself. Use package-private (no modifier) or a getter.
