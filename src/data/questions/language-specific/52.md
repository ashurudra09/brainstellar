## Question
Output?

```cpp
struct P1 { virtual void h(int){cout<<"P1";} };
struct P2 : P1 { void h(double){cout<<"P2";} };
P2 q; P1& r = q;
r.h(1); q.h(1);
```

## Options
- P1P2
- P2P2
- P1P1
- Compile error

## Answer
**A.** P1P2

## Solution
h(double) has a different signature, so it hides P1::h(int) instead of overriding it. Through a P1& the call goes to P1::h. Through q, only P2::h(double) is visible, and 1 is converted to 1.0.
