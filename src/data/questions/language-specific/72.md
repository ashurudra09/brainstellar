## Question
Output?

```java
class T {
    static { System.out.print("S"); }
    { System.out.print("I"); }
    T() { System.out.print("C"); }
}
// main: new T(); new T();
```

## Options
- SICIC
- SICSIC
- ICSIC
- SCICI

## Answer
**A.** SICIC

## Solution
The static block runs once, when the class loads. For each object, the instance initialiser runs before the constructor body.
