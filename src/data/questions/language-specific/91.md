## Question
Output?

```python
a = [1, 2]
b = a
b += [3]
print(a)
```

## Options
- \[1, 2, 3\]
- \[1, 2\]
- Error
- \[3\]

## Answer
**A.** \[1, 2, 3\]

## Solution
b is another name for the same list, and += on a list changes it in place.
