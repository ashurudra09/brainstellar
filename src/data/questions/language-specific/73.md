## Question
Output?

```java
class P { P(){ System.out.print("P"); } }
class C extends P { C(){ System.out.print("C"); } }
// main: new C();
```

## Options
- PC
- C
- CP
- Compile error

## Answer
**A.** PC

## Solution
The compiler inserts super() as the first statement of C's constructor, so the parent's constructor runs first.
