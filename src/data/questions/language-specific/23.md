## Question
Output?

```c
int a = 0, b = 5;
if (a && b++) { }
printf("%d", b);
```

## Options
- 5
- 6
- 0
- Undefined

## Answer
**A.** 5

## Solution
a is 0, so && short-circuits and b++ never runs.
