## Question
Output?

```c
int x = (1, 2, 3);
printf("%d", x);
```

## Options
- 3
- 1
- 6
- Compile error

## Answer
**A.** 3

## Solution
The comma operator evaluates its operands left to right and returns the last one. (Without the parentheses, int x = 1, 2, 3; is a syntax error.)
