## Question
Output?

```python
t = ([1],)
t[0].append(2)
print(t)
```

## Options
- (\[1, 2\],)
- TypeError
- (\[1\],)
- \[1, 2\]

## Answer
**A.** (\[1, 2\],)

## Solution
The tuple still holds the same list object, so the tuple hasn't changed. The list inside it is mutable.
