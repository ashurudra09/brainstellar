## Question
Output?

```java
int m = Integer.MAX_VALUE;
System.out.println(m + 1);
```

## Options
- \-2147483648
- 2147483648
- Throws ArithmeticException
- 0

## Answer
**A.** \-2147483648

## Solution
Integer overflow wraps around silently in two's complement. Only Math.addExact throws.
