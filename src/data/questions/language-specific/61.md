## Question
In which order are the members initialised?

```cpp
struct S {
    int a, b;
    S(int x) : b(x), a(b + 1) {}
};
```

## Options
- a then b, so a reads an uninitialised b
- b then a, so a = x + 1
- In parallel
- Compile error

## Answer
**A.** a then b, so a reads an uninitialised b

## Solution
Members are initialised in declaration order (a, then b), whatever the order of the initialiser list. a is set from b before b has a value.
