## Question
Output?

```c
printf("%d %d", -7 / 2, -7 % 2);
```

## Options
- \-3 -1
- \-4 1
- \-3 1
- \-4 -1

## Answer
**A.** \-3 -1

## Solution
C truncates toward zero, and the remainder takes the sign of the dividend. (Python would give −4 1.)
