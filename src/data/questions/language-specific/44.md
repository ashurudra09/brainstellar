## Question
Output?

```cpp
struct C { static int n; C(){ n++; } };
int C::n = 0;
int main() { C a, b[3]; cout << C::n; }
```

## Options
- 4
- 1
- 3
- 0

## Answer
**A.** 4

## Solution
One shared counter: a plus the 3 elements of b means 4 constructor calls.
