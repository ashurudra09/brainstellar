## Question
Output?

```cpp
unordered_map<int,int> um;
um[1]++; um[1]++;
cout << um[1] << " " << um.count(2);
```

## Options
- 2 0
- 2 1
- 1 0
- Compile error

## Answer
**A.** 2 0

## Solution
The first um\[1\] inserts 0, then the two ++ make it 2. count doesn't insert anything, and 2 isn't a key.
