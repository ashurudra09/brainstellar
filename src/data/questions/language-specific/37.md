## Question
Output?

```c
char s[] = "MathWorks";
printf("%s", s + 4);
```

## Options
- Works
- MathW
- W
- orks

## Answer
**A.** Works

## Solution
s + 4 points at index 4 ('W'), and %s prints from there to the '\\0'.
