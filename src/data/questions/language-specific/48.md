## Question
Output?

```cpp
map<string,int> m;
m["b"] = 2; m["a"] = 1; m["c"];
cout << m.size() << " " << m.begin()->first;
```

## Options
- 3 a
- 2 b
- 2 a
- 3 b

## Answer
**A.** 3 a

## Solution
Just reading m\["c"\] inserts "c" with the value 0. A std::map keeps its keys sorted, so begin() is "a".
