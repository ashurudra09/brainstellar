## Question
Output?

```c
int a[5] = {1, 2};
printf("%d %d", a[1], a[4]);
```

## Options
- 2 0
- 2 garbage
- 1 0
- Compile error

## Answer
**A.** 2 0

## Solution
With a partial initialiser, the remaining elements are zeroed, even for a local array.
