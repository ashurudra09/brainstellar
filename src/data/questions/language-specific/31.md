## Question
Output in C (not C++)?

```c
printf("%zu", sizeof(char) + sizeof('a'));
```

## Options
- 5
- 2
- 8
- 1

## Answer
**A.** 5

## Solution
In C a character literal has type int (4 bytes): 1 + 4 = 5. In C++ 'a' is a char, so the answer would be 2.
