## Question
Why make a base class's destructor virtual?

## Options
- So that deleting a derived object through a base pointer runs the derived destructor
- To make the class abstract
- To speed up destruction
- To stop the class being inherited

## Answer
**A.** So that deleting a derived object through a base pointer runs the derived destructor

## Solution
Without it, delete basePtr runs only \~Base, which is undefined behaviour and usually leaks whatever Derived owns.
