## Question
Output?

```c
int z = 0x10 + 010;
printf("%d", z);
```

## Options
- 24
- 20
- 18
- 26

## Answer
**A.** 24

## Solution
0x10 is hex 16 and 010 is octal 8, so the sum is 24. A leading 0 makes a literal octal.
