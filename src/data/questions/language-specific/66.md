## Question
Output (two lines)?

```java
System.out.println('a' + 1);
System.out.println("" + 'a' + 1);
```

## Options
- 98 / a1
- b / a1
- 98 / 98
- a1 / a1

## Answer
**A.** 98 / a1

## Solution
char + int is numeric addition (97 + 1). Once a String is on the left, every + concatenates.
