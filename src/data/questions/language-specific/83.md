## Question
Output?

```java
List<Integer> li = new ArrayList<>(List.of(10, 20, 30));
li.remove(1);
li.remove(Integer.valueOf(10));
System.out.println(li);
```

## Options
- \[30\]
- \[20, 30\]
- \[10, 30\]
- \[20\]

## Answer
**A.** \[30\]

## Solution
remove(int) removes by index (20 goes). remove(Object) removes by value (10 goes).
