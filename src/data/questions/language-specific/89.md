## Question
Output?

```python
def f(x, l=[]):
    l.append(x)
    return l
f(1)
print(f(2))
```

## Options
- \[1, 2\]
- \[2\]
- \[1\]
- Error

## Answer
**A.** \[1, 2\]

## Solution
Default values are created once, when the function is defined, so every call shares the same list. Use l=None and create the list inside the function.
