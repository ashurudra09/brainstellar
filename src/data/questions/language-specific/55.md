## Question
Output?

```cpp
priority_queue<int> pq;
for (int y : {4, 9, 2}) pq.push(y);
cout << pq.top();
```

## Options
- 9
- 2
- 4
- Compile error

## Answer
**A.** 9

## Solution
priority\_queue is a max-heap by default. Use greater\<int\> as the comparator for a min-heap.
