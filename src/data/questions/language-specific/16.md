## Question
Output?

```c
int cnt() { static int c = 0; return ++c; }
int main() {
    cnt(); cnt();
    printf("%d", cnt());
}
```

## Options
- 3
- 1
- 0
- Compile error

## Answer
**A.** 3

## Solution
A static local is initialised only once and keeps its value between calls: 1, 2, 3.
