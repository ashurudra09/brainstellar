## Question
Output?

```java
static void ov(long x){System.out.print("long");}
static void ov(Integer x){System.out.print("Integer");}
static void ov2(Object o){System.out.print("Object");}
static void ov2(String s){System.out.print("String");}
// main: ov(5); ov2(null);
```

## Options
- long String
- Integer String
- long Object
- Compile error

## Answer
**A.** long String

## Solution
Overload priority: widening (int → long) beats boxing (int → Integer). For null, the most specific type (String) is chosen over Object.
