## Question
Base\* p = new Derived(); delete p;  where Base's destructor is NOT virtual. What happens?

## Options
- Both destructors run
- Only Base's destructor runs (UB)
- Only Derived's runs
- Compile error

## Answer
**B.** Only Base's destructor runs (UB)

## Solution
Without virtual, the call is resolved by the pointer's type (Base), so Derived's destructor never runs and its resources leak. Formally this is undefined behaviour (UB).
