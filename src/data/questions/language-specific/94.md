## Question
Output?

```python
g = (x * x for x in range(3))
print(sum(g), sum(g))
```

## Options
- 5 0
- 5 5
- 0 5
- Error

## Answer
**A.** 5 0

## Solution
A generator can be used up only once: 0 + 1 + 4 = 5, and the second sum sees nothing left.
