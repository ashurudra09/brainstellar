## Question
Output?

```python
s = "abcdef"
print(s[::-2], s[-3:], s[1:4])
```

## Options
- fdb def bcd
- fdb abc bcd
- eca def bcd
- fdb def bcde

## Answer
**A.** fdb def bcd

## Solution
\[::-2\] goes backwards from the end in steps of 2: f, d, b. \[-3:\] is the last 3 characters. \[1:4\] is indices 1 to 3.
