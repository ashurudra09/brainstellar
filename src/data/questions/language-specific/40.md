## Question
Output?

```cpp
struct A { A(){cout<<"A";} ~A(){cout<<"~A";} };
struct B : A { B(){cout<<"B";} ~B(){cout<<"~B";} };
int main() { B b; }
```

## Options
- AB\~B\~A
- AB\~A\~B
- BA\~B\~A
- B\~B

## Answer
**A.** AB\~B\~A

## Solution
Construction runs base then derived. Destruction runs in exactly the reverse order.
