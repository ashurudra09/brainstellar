## Question
Output?

```python
print(list(zip([1, 2, 3], 'ab')), {1, 2, 3} ^ {2, 3, 4})
```

## Options
- \[(1, 'a'), (2, 'b')\] {1, 4}
- \[(1, 'a'), (2, 'b'), (3, None)\] {1, 4}
- \[(1, 'a'), (2, 'b')\] {2, 3}
- Error

## Answer
**A.** \[(1, 'a'), (2, 'b')\] {1, 4}

## Solution
zip stops at the shortest input. ^ is the symmetric difference: elements in exactly one of the sets.
