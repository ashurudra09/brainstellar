## Question
Output?

```java
String s = "abc";
s.toUpperCase();
System.out.println(s);
```

## Options
- abc
- ABC
- Compile error
- null

## Answer
**A.** abc

## Solution
Strings are immutable, and the new string was thrown away. You need s = s.toUpperCase().
