## Question
Output?

```cpp
int arr[] = {1, 2, 3};
int* p = arr;
cout << *p++ << " ";
cout << *p;
```

## Options
- 1 2
- 2 2
- 1 1
- 2 3

## Answer
**A.** 1 2

## Solution
Postfix ++ binds tighter than \*, but it returns the old pointer. So the first line reads arr\[0\] and then p advances.
