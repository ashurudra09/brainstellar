## Question
Output?

```c
unsigned int u = 1;
int i = -1;
if (i < u) printf("A");
else printf("B");
```

## Options
- B
- A
- Compile error
- Undefined

## Answer
**A.** B

## Solution
i is converted to unsigned, so −1 becomes 4294967295, which is greater than 1.
