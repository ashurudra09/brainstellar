## Question
Output?

```cpp
struct B { B(){ show(); } virtual void show(){cout<<"B";} };
struct D : B { void show() override {cout<<"D";} };
int main() { D d; }
```

## Options
- B
- D
- BD
- Compile error

## Answer
**A.** B

## Solution
While B's constructor runs, the object is still only a B (D's part isn't built yet), so the call goes to B::show.
