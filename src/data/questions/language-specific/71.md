## Question
Output?

```java
int[] a = new int[3];
String[] s = new String[2];
System.out.println(a[1] + " " + s[0]);
```

## Options
- 0 null
- garbage null
- 0 ""
- Compile error

## Answer
**A.** 0 null

## Solution
Array elements get default values: 0, false or null. (A local variable that isn't initialised is a compile error.)
