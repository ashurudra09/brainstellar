## Question
Output?

```python
fs = [lambda: i for i in range(3)]
print([f() for f in fs])
```

## Options
- \[2, 2, 2\]
- \[0, 1, 2\]
- \[0, 0, 0\]
- Error

## Answer
**A.** \[2, 2, 2\]

## Solution
Late binding: each lambda looks up i when it's called, and by then i is 2. Fix it with lambda i=i: i.
