## Question
In C++, which of these cannot be virtual?

## Options
- Destructor
- Constructor
- Member function
- Operator overload

## Answer
**B.** Constructor

## Solution
Virtual dispatch uses the object's vptr, and the constructor is what sets the vptr up. There's no object yet to dispatch on.
