## Question
Output?

```c
int n = 0;
while (n++ < 3);
printf("%d", n);
```

## Options
- 4
- 3
- 0
- Infinite loop

## Answer
**A.** 4

## Solution
The comparison uses the old value, then n increments. The checks 0\<3, 1\<3 and 2\<3 pass, and 3\<3 fails, but n++ still runs, so n = 4.
