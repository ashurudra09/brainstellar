## Question
Output?

```c
char *p = "abc";
printf("%c", *p + 1);
```

## Options
- b
- a
- 98
- bc

## Answer
**A.** b

## Solution
\*p is 'a' (97), and 97 + 1 = 98, which %c prints as 'b'. Compare \*(p+1), which is also 'b' but by indexing.
