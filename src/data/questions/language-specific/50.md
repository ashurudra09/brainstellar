## Question
Output?

```cpp
int x = 10;
int main() {
    int x = 20;
    cout << x << ::x;
}
```

## Options
- 2010
- 2020
- 1010
- 1020

## Answer
**A.** 2010

## Solution
The local x shadows the global one. ::x reaches the global.
