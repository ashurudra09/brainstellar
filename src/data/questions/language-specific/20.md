## Question
Output?

```c
int x = 2;
switch (x) {
    case 1: printf("1");
    case 2: printf("2");
    case 3: printf("3"); break;
    default: printf("d");
}
```

## Options
- 23
- 2
- 23d
- 123

## Answer
**A.** 23

## Solution
Execution enters at case 2 and falls through into case 3 until the break.
