## Question
What does this print?

```c
int i = 5;
i = i++ + ++i;
printf("%d", i);
```

## Options
- Undefined behaviour
- 12
- 11
- 13

## Answer
**A.** Undefined behaviour

## Solution
i is modified twice without a sequence point in between, which is undefined behaviour. Different compilers print different numbers. If 'undefined' is an option, pick it.
