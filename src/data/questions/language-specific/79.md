## Question
Output?

```java
int i = 0;
boolean b = (i++ > 0) && (i++ > 0);
System.out.println(i);
```

## Options
- 1
- 2
- 0
- Compile error

## Answer
**A.** 1

## Solution
0 \> 0 is false, so && short-circuits and the second i++ never runs.
