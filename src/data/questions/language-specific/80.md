## Question
Output?

```java
System.out.println(true ? 1 : 2.0);
```

## Options
- \1.0
- 1
- \2.0
- Compile error

## Answer
**A.** \1.0

## Solution
The ternary operator gives both branches a common numeric type (double), so 1 prints as 1.0.
