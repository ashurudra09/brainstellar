## Question
Output?

```java
byte b = (byte) 200;
char ch = 'A';
ch += 2;
System.out.println(b + " " + ch);
```

## Options
- \-56 C
- 200 C
- \-56 67
- Compile error

## Answer
**A.** \-56 C

## Solution
200 − 256 = −56. += includes a hidden cast, so ch becomes 'C'. (ch = ch + 2 would not compile.)
