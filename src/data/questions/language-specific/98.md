## Question
Output?

```python
l = [3, 1, 2]
r = l.sort()
print(r, l)
```

## Options
- None \[1, 2, 3\]
- \[1, 2, 3\] \[1, 2, 3\]
- \[1, 2, 3\] \[3, 1, 2\]
- Error

## Answer
**A.** None \[1, 2, 3\]

## Solution
list.sort() sorts in place and returns None. sorted(l) returns a new list.
