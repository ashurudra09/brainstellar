## Question
What happens?

```cpp
struct S { virtual void f() = 0; };
int main() { S s; }
```

## Options
- Compile error: S is abstract
- Runs fine
- Linker error
- Runtime error

## Answer
**A.** Compile error: S is abstract

## Solution
A class with a pure virtual function can't be instantiated. S\* and S& are fine.
