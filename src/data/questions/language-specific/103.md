## Question
Output (NumPy) for np.array(\[1, 2, 3\]) \* 2 compared with \[1, 2, 3\] \* 2?

## Options
- \[2 4 6\] and \[1, 2, 3, 1, 2, 3\]
- Both \[2, 4, 6\]
- Both \[1, 2, 3, 1, 2, 3\]
- Error

## Answer
**A.** \[2 4 6\] and \[1, 2, 3, 1, 2, 3\]

## Solution
NumPy applies the operation to each element (broadcasting). A plain Python list repeats itself.
