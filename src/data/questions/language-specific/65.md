## Question
Output?

```java
Integer x = 127, y = 127, p = 128, q = 128;
System.out.println((x == y) + " " + (p == q));
```

## Options
- true false
- true true
- false false
- false true

## Answer
**A.** true false

## Solution
Autoboxing caches Integer values from −128 to 127, so 128 creates two separate objects and == compares references.
