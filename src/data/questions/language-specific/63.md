## Question
What is the diamond problem solved with?

## Options
- Virtual inheritance
- Pure virtual functions
- Friend classes
- Templates

## Answer
**A.** Virtual inheritance

## Solution
class B : virtual public A and class C : virtual public A make D share a single A subobject.
