## Question
Output?

```cpp
struct X { X(){cout<<"c";} X(const X&){cout<<"k";} };
void byVal(X x) {}
void byRef(X& x) {}
int main() { X a; X b = a; byVal(a); byRef(a); }
```

## Options
- ckk
- ckkk
- cck
- ck

## Answer
**A.** ckk

## Solution
X a uses the default ctor (c). X b = a calls the copy ctor (k), and so does passing by value (k). Passing by reference makes no copy.
