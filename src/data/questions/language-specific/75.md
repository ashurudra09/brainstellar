## Question
Output?

```java
System.out.println(10 / 3 + " " + 10 % 3 + " " + -10 % 3);
```

## Options
- 3 1 -1
- 3 1 2
- \3.33 1 -1
- 3 1 1

## Answer
**A.** 3 1 -1

## Solution
Integer division truncates. The sign of % follows the dividend, as in C (Python would give 2).
