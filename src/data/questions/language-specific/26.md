## Question
sizeof(struct S) on a typical 32/64-bit compiler?

```c
struct S { char c; int i; char d; };
```

## Options
- 12
- 6
- 8
- 9

## Answer
**A.** 12

## Solution
c (1) + 3 bytes padding + i (4) + d (1) + 3 trailing padding = 12. Reordering to {int; char; char;} gives 8.
