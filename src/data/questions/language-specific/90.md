## Question
Output?

```python
m = [[0] * 2] * 2
m[0][0] = 1
print(m)
```

## Options
- \[\[1, 0\], \[1, 0\]\]
- \[\[1, 0\], \[0, 0\]\]
- \[\[1, 1\], \[0, 0\]\]
- Error

## Answer
**A.** \[\[1, 0\], \[1, 0\]\]

## Solution
The outer \* 2 repeats a reference to the same inner list. Use \[\[0\]\*2 for \_ in range(2)\].
