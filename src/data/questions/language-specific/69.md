## Question
Output?

```java
static int f() { try { return 1; } finally { return 2; } }
static int g() { int x = 1; try { return x; } finally { x = 5; } }
// prints f() + " " + g()
```

## Options
- 2 1
- 1 1
- 2 5
- 1 5

## Answer
**A.** 2 1

## Solution
A return in finally replaces the try's return. In g, the return value 1 was already saved, so changing x afterwards doesn't affect it.
