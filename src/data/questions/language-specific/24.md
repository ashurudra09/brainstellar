## Question
Output?

```c
printf("%d", printf("hello"));
```

## Options
- hello5
- 5hello
- hello
- 5

## Answer
**A.** hello5

## Solution
The inner printf runs first and prints hello. It returns the number of characters printed (5), which the outer printf then prints.
