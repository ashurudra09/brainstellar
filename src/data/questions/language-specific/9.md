## Question
For class D : public B, what is the order of calls on creation and then destruction?

## Options
- B(), D() … \~B(), \~D()
- B(), D() … \~D(), \~B()
- D(), B() … \~D(), \~B()
- D(), B() … \~B(), \~D()

## Answer
**B.** B(), D() … \~D(), \~B()

## Solution
The base must exist before the derived part that builds on it, so construction goes base first. Destruction is the exact reverse: the derived part is cleaned up while the base is still intact.
