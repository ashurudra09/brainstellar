## Question
Output?

```java
Map<String,Integer> hm = new HashMap<>();
hm.put("k", 1); hm.put("k", 2);
System.out.println(hm.size() + " " + hm.get("k") + " " + hm.get("z"));
```

## Options
- 1 2 null
- 2 2 null
- 1 1 null
- 1 2 0

## Answer
**A.** 1 2 null

## Solution
put with an existing key replaces the value. get on a missing key returns null; it doesn't throw.
