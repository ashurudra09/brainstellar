## Question
Output?

```c
int x = 10;
int *p = &x;
int **q = &p;
**q = 20;
printf("%d", x);
```

## Options
- 20
- 10
- Address of x
- Compile error

## Answer
**A.** 20

## Solution
\*\*q follows q to p and then p to x, so the assignment writes 20 into x.
