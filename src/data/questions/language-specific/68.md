## Question
Output?

```java
class A { static void s(){System.out.print("A");} void i(){System.out.print("a");} }
class B extends A { static void s(){System.out.print("B");} void i(){System.out.print("b");} }
A o = new B();
o.s(); o.i();
```

## Options
- Ab
- Bb
- Aa
- Ba

## Answer
**A.** Ab

## Solution
Static methods are hidden, not overridden, so the declared type (A) is used. Instance methods are chosen by the runtime type (B).
