## Question
Which is TRUE about Java interfaces (Java 8+)?

## Options
- They can have default and static methods
- Their fields can be private instance variables
- A class can implement only one
- They can have constructors

## Answer
**A.** They can have default and static methods

## Solution
Interface fields are implicitly public static final. Interfaces can't have constructors. A class can implement any number of them.
