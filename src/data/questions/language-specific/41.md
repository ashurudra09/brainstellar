## Question
Output?

```cpp
struct Base { virtual void f(){cout<<"Base";} void g(){cout<<"BaseG";} };
struct D : Base { void f() override {cout<<"D";} void g(){cout<<"DG";} };
Base* p = new D;
p->f(); p->g();
```

## Options
- DBaseG
- DDG
- BaseBaseG
- BaseDG

## Answer
**A.** DBaseG

## Solution
f is virtual, so the object's real type (D) decides. g is not virtual, so the pointer's type (Base) decides.
