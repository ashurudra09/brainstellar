## Question
Output on a 64-bit system?

```c
void f(int a[]) { printf("%zu", sizeof(a)); }
int main() {
    int a[10];
    printf("%zu ", sizeof(a));
    f(a);
}
```

## Options
- 40 8
- 40 40
- 8 8
- 10 10

## Answer
**A.** 40 8

## Solution
Inside main, a is a real array: 10 × 4 = 40. As a parameter, int a\[\] is really int \*a, which is 8 bytes on 64-bit.
