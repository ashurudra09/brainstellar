## Question
With no access keyword, what is the default access for class members and for class inheritance?

## Options
- private, private
- public, public
- private, public
- protected, private

## Answer
**A.** private, private

## Solution
class defaults to private for both members and inheritance. struct defaults to public for both. That is the only difference between them.
