## Question
Java: String a = "hi"; String b = new String("hi"); What is a == b?

## Options
- true
- false
- Compile error
- Depends on JVM

## Answer
**B.** false

## Solution
== compares references. a points to the pooled literal; new always creates a separate object. a.equals(b) compares characters and is true.
