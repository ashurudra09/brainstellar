## Question
Runtime polymorphism in C++ is achieved through:

## Options
- Function overloading
- Templates
- Virtual functions
- Operator overloading

## Answer
**C.** Virtual functions

## Solution
A virtual call goes through the object's vtable at runtime, so the derived version runs even through a base pointer. Overloading and templates are resolved by the compiler (compile-time polymorphism).
