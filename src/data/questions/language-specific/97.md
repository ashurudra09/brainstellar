## Question
Output?

```python
print(len({1: 'a', True: 'b', 1.0: 'c'}))
```

## Options
- 1
- 3
- 2
- Error

## Answer
**A.** 1

## Solution
1 == True == 1.0 and their hashes are equal, so all three are the same key. The dict ends up as {1: 'c'}.
