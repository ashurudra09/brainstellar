## Question
What happens?

```cpp
struct B { void f(){} };
struct D : B { void f(int){} };
int main() { D d; d.f(); }
```

## Options
- Compile error: no matching D::f()
- Calls B::f
- Calls D::f(0)
- Runtime error

## Answer
**A.** Compile error: no matching D::f()

## Solution
Name hiding: once the compiler finds f in D, it stops looking in B. Add using B::f; inside D to bring it back.
