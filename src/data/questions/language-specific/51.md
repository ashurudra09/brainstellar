## Question
Output?

```cpp
struct T { int id; T(int i):id(i){cout<<id;} ~T(){cout<<id;} };
int main() { T a(1), b(2); }
```

## Options
- 1221
- 1212
- 2112
- 12

## Answer
**A.** 1221

## Solution
Locals are destroyed in reverse order of construction: built 1, 2 and destroyed 2, 1.
