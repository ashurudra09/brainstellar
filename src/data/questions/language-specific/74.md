## Question
Output?

```java
static void m(int[] a) { a[0] = 9; a = new int[]{7}; }
// main:
int[] x = {1};
m(x);
System.out.println(x[0]);
```

## Options
- 9
- 7
- 1
- Compile error

## Answer
**A.** 9

## Solution
Java passes a copy of the reference. Changing the array it points to is visible to the caller. Reassigning a points the local copy elsewhere.
