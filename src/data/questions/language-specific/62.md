## Question
const int \*p versus int \*const p:

## Options
- First: the value is read-only. Second: the pointer is fixed
- Both make the value read-only
- First: the pointer is fixed. Second: the value is read-only
- They're identical

## Answer
**A.** First: the value is read-only. Second: the pointer is fixed

## Solution
Read right to left: p is a pointer to a const int, versus p is a const pointer to an int.
