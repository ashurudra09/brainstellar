## Question
Output (typical compiler, signed char)?

```c
char c = 127;
c++;
printf("%d", c);
```

## Options
- \-128
- 128
- 0
- 127

## Answer
**A.** \-128

## Solution
A signed 8-bit char wraps from 127 to −128. Strictly speaking this is implementation-defined, but −128 is the expected MCQ answer.
