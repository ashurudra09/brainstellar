## Question
Output (NumPy)?

```python
import numpy as np
a = np.arange(6).reshape(2, 3)
print(a.sum(axis=0))
```

## Options
- \[3 5 7\]
- \[3 12\]
- 15
- \[0 1 2\]

## Answer
**A.** \[3 5 7\]

## Solution
a = \[\[0,1,2\],\[3,4,5\]\]. axis=0 collapses the rows, giving column sums. axis=1 would give \[3 12\].
