## Question
Output?

```c
int a[2][3] = {1, 2, 3, 4, 5, 6};
printf("%d", *(*(a + 1) + 2));
```

## Options
- 6
- 5
- 4
- 3

## Answer
**A.** 6

## Solution
\*(\*(a+i)+j) is a\[i\]\[j\], and a\[1\]\[2\] = 6.
