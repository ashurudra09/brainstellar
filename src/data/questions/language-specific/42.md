## Question
Output? (same Base and D as above)

```cpp
D d;
Base b = d;
b.f();
```

## Options
- Base
- D
- Compile error
- Undefined

## Answer
**A.** Base

## Solution
Object slicing: b is a real Base object, built by copying only the Base part of d. Virtual dispatch only works through pointers and references.
