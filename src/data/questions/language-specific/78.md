## Question
Output?

```java
StringBuilder sb = new StringBuilder("ab");
sb.append("c").reverse();
System.out.println(sb);
```

## Options
- cba
- abc
- ab
- cab

## Answer
**A.** cba

## Solution
StringBuilder methods modify the builder in place and return it, so calls can be chained.
