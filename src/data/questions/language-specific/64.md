## Question
Output?

```java
String a = "hi", b = "hi", c = new String("hi");
System.out.println((a == b) + " " + (a == c) + " " + a.equals(c));
```

## Options
- true false true
- true true true
- false false true
- true false false

## Answer
**A.** true false true

## Solution
Equal literals share one object in the string pool. new String always creates a new object. equals compares content.
