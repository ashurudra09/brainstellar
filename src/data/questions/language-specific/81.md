## Question
Output?

```java
class F { int x = 10; }
class G extends F { int x = 20; }
F f = new G();
System.out.println(f.x);
```

## Options
- 10
- 20
- Compile error
- 0

## Answer
**A.** 10

## Solution
Fields are not polymorphic: the reference type (F) decides which x you get. Only methods are dispatched at runtime.
