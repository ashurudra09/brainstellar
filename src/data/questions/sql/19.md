## Question
Which query correctly returns the average number of customers per city?

## Options
- SELECT AVG(COUNT(\*)) FROM customers GROUP BY city\_id
- SELECT AVG(cnt) FROM (SELECT COUNT(\*) AS cnt FROM customers GROUP BY city\_id) t
- SELECT COUNT(AVG(city\_id)) FROM customers
- SELECT AVG(\*) FROM customers GROUP BY city\_id

## Answer
**B.** SELECT AVG(cnt) FROM (SELECT COUNT(\*) AS cnt FROM customers GROUP BY city\_id) t

## Solution
Aggregates can't be nested. Compute the per-city counts in a derived table, then average that column. Add WHERE city\_id IS NOT NULL so NULL-city customers don't form an extra group.
