## Question
customers.city\_id values are 1, 1, 2, NULL, NULL. How many rows does SELECT COUNT(\*) FROM customers GROUP BY city\_id return?

## Options
- 2
- 3
- 4
- 5

## Answer
**B.** 3

## Solution
GROUP BY puts all NULLs into one group, giving three groups: 1 (count 2), 2 (count 1) and NULL (count 2). That's how a NULL group silently skews an average of the counts.
