## Question
start\_date and end\_date are VARCHAR(19) like '2026-03-01 10:00:00'. Which PostgreSQL expression gives the session length in minutes?

## Options
- end\_date - start\_date
- DATEDIFF(minute, start\_date, end\_date)
- EXTRACT(EPOCH FROM end\_date::timestamp - start\_date::timestamp) / 60
- TIMESTAMPDIFF(MINUTE, start\_date, end\_date)

## Answer
**C.** EXTRACT(EPOCH FROM end\_date::timestamp - start\_date::timestamp) / 60

## Solution
Text can't be subtracted, so cast to timestamp first. Timestamp minus timestamp gives an INTERVAL, and EXTRACT(EPOCH FROM …) turns it into seconds. DATEDIFF is SQL Server syntax and TIMESTAMPDIFF is MySQL; neither exists in Postgres.
