## Question
Which statement is DDL, cannot take a WHERE clause and removes all rows quickly?

## Options
- DELETE
- TRUNCATE
- DROP
- UPDATE

## Answer
**B.** TRUNCATE

## Solution
TRUNCATE is data-definition language (DDL) and drops all rows at once. DELETE is data-manipulation language (DML), works row by row and accepts WHERE. DROP removes the table itself.
