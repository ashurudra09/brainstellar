## Question
In PostgreSQL, what does SELECT 7 / 2; return?

## Options
- \3.5
- 3
- 4
- Error

## Answer
**B.** 3

## Solution
Both operands are integers, so Postgres does integer division and drops the fraction. Write 7::numeric / 2 or 7 / 2.0 to get 3.5.
