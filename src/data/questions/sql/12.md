## Question
After a crash, money is debited from A but never credited to B. Which ACID property failed?

## Options
- Atomicity
- Consistency
- Isolation
- Durability

## Answer
**A.** Atomicity

## Solution
Atomicity means all or nothing. Half the transfer was applied, and recovery should have undone it using the undo log.
