## Question
Composite index on (a, b, c). Which predicate can NOT use the index efficiently?

## Options
- WHERE a = 1
- WHERE a = 1 AND b = 2
- WHERE b = 2
- WHERE a = 1 AND b = 2 AND c = 3

## Answer
**C.** WHERE b = 2

## Solution
The index is sorted by a first, then b within each a. Without a, the matching b values are scattered all over, like looking up a first name in a phone book sorted by surname (the left-prefix rule).
