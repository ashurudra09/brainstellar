## Question
To keep only the last price of each day for each coin, which window should you number by and keep rn = 1?

## Options
- ROW\_NUMBER() OVER (PARTITION BY coin ORDER BY ts DESC)
- ROW\_NUMBER() OVER (PARTITION BY coin, ts::date ORDER BY ts DESC)
- ROW\_NUMBER() OVER (PARTITION BY ts::date ORDER BY ts ASC)
- RANK() OVER (ORDER BY price DESC)

## Answer
**B.** ROW\_NUMBER() OVER (PARTITION BY coin, ts::date ORDER BY ts DESC)

## Solution
Number the rows separately for each (coin, day) pair, newest first, so rn = 1 is that day's closing price. Without ts::date you'd get only one row per coin overall, and ASC would pick the opening price.
