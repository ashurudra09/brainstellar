## Question
Which normal form removes transitive dependencies?

## Options
- 3NF
- 2NF
- 1NF
- 4NF

## Answer
**A.** 3NF

## Solution
2NF removes partial dependencies on part of a composite key. 3NF removes non-key → non-key dependencies (transitive ones).
