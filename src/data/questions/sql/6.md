## Question
R(A,B,C,D) with functional dependencies A→B, B→C, C→D. Highest normal form?

## Options
- 1NF
- 2NF
- 3NF
- BCNF

## Answer
**B.** 2NF

## Solution
A⁺ = ABCD, so A alone is the key. A single-column key can't have partial dependencies, so the table is in 2NF. B→C has a non-key determinant (B) and a non-prime dependent (C), a transitive dependency that breaks 3NF.
