## Question
What happens when this runs?

```sql
SELECT coin, price,
       ROW_NUMBER() OVER (PARTITION BY coin ORDER BY ts DESC) AS rn
FROM prices
WHERE rn = 1;
```

## Options
- Returns the latest row per coin
- Error: rn can't be used in WHERE of the same query
- Returns every row
- Returns no rows

## Answer
**B.** Error: rn can't be used in WHERE of the same query

## Solution
WHERE runs before window functions are computed, so rn doesn't exist yet. Put the ROW\_NUMBER in a CTE or subquery and filter rn = 1 outside it.
