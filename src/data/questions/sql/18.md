## Question
daily\_revenue has rows (Jan 1, 100), (Jan 2, 150), (Jan 3, 120). What is revenue\_delta for Jan 1?

```sql
SELECT date, revenue - LAG(revenue) OVER (ORDER BY date) AS revenue_delta
FROM daily_revenue;
```

## Options
- 0
- NULL
- 100
- Error

## Answer
**B.** NULL

## Solution
Jan 1 has no previous row, so LAG returns NULL, and 100 − NULL is NULL. Jan 2 gets 50 and Jan 3 gets −30. Use COALESCE if 0 is wanted.
