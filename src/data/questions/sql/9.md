## Question
Which clause filters groups after aggregation?

## Options
- WHERE
- HAVING
- GROUP BY
- ORDER BY

## Answer
**B.** HAVING

## Solution
SQL runs FROM → WHERE → GROUP BY → HAVING. WHERE runs before groups exist, so conditions like SUM(x) \> 100 must go in HAVING.
