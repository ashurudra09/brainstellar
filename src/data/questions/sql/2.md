## Question
Given `Employee(id, name, salary, department_id)` and `Department(id, name)`, find the top 2 highest-paid employees in each department.

## Schema
```sql
CREATE TABLE Employee (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    salary INT,
    department_id INT
);

CREATE TABLE Department (
    id INT PRIMARY KEY,
    name VARCHAR(50)
);
```

## Hint
A plain `GROUP BY` can only give you one aggregate row per department -- ranking "top 2 within each group" needs a window function.

## Query
```sql
WITH ranked AS (
    SELECT
        e.name,
        e.salary,
        d.name AS department,
        DENSE_RANK() OVER (
            PARTITION BY e.department_id ORDER BY e.salary DESC
        ) AS rnk
    FROM Employee e
    JOIN Department d ON d.id = e.department_id
)
SELECT department, name, salary
FROM ranked
WHERE rnk <= 2;
```

## Solution
`DENSE_RANK() OVER (PARTITION BY department_id ORDER BY salary DESC)` resets the ranking independently for each department and gives tied salaries the same rank without leaving a gap in the sequence (unlike plain `RANK()`), which is usually what "top 2" should mean when there's a tie for second place. Filtering the CTE on `rnk <= 2` then keeps exactly the top two salary tiers per department.
