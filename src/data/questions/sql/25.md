## Question
How does a UNIQUE constraint differ from a PRIMARY KEY?

## Options
- UNIQUE allows NULLs, and a table can have several
- UNIQUE allows duplicates
- A PRIMARY KEY allows NULLs
- No difference

## Answer
**A.** UNIQUE allows NULLs, and a table can have several

## Solution
A primary key = UNIQUE + NOT NULL, and a table has only one. You can have many UNIQUE columns, and they accept NULLs.
