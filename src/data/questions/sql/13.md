## Question
A schedule's precedence graph contains a cycle. The schedule is:

## Options
- Conflict serializable
- Not conflict serializable
- Recoverable
- Cascadeless

## Answer
**B.** Not conflict serializable

## Solution
An edge Ti → Tj means Ti must come before Tj in any equivalent serial order. A cycle demands that some transaction come before itself, so no such order exists.
