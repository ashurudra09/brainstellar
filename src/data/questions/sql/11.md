## Question
Best index structure for range queries such as WHERE price BETWEEN 100 AND 500?

## Options
- Hash index
- B+ tree
- Bitmap only
- No index

## Answer
**B.** B+ tree

## Solution
B+ tree leaves are sorted and linked, so it finds 100 in O(log n) and walks along the leaves to 500. A hash index scatters keys and only helps with equality.
