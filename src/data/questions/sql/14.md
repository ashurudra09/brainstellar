## Question
A has ids {1,2,3}; B has ids {2,3,3,4}. Rows in A LEFT JOIN B ON A.id = B.id?

## Options
- 3
- 4
- 5
- 6

## Answer
**B.** 4

## Solution
Go key by key: id 1 has no match, so 1 NULL-padded row; id 2 gives 1 × 1 = 1; id 3 gives 1 × 2 = 2. Total 4. A left join never returns fewer rows than the left table.
