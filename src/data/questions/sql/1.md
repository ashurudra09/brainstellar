## Question
Write a query to find the second-highest salary from the `Employee` table. If there is no second-highest salary, return `NULL`.

## Schema
```sql
CREATE TABLE Employee (
    id     INT PRIMARY KEY,
    salary INT
);
```

## Hint
`MAX()` alone only gets you the highest. You need to exclude that value before taking a max again -- or use `LIMIT`/`OFFSET` on a sorted list.

## Query
```sql
SELECT MAX(salary) AS SecondHighestSalary
FROM Employee
WHERE salary < (SELECT MAX(salary) FROM Employee);
```

## Solution
The subquery finds the single highest salary. The outer query then takes the max salary strictly less than that -- which is exactly the second-highest. Wrapping it as `MAX(...)` (rather than `LIMIT 1`) also means the query returns `NULL` automatically when there's zero or one distinct salary, instead of erroring or returning an empty result set.
