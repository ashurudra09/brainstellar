## Question
CAP theorem: during a network partition, a CP system gives up:

## Options
- Consistency
- Availability
- Partition tolerance
- Durability

## Answer
**B.** Availability

## Solution
CP means Consistency + Partition tolerance. To never return stale data, it refuses or blocks some requests while nodes can't talk to each other, so availability is lost.
