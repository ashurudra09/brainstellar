## Question
Which isolation level prevents dirty reads but still allows non-repeatable reads?

## Options
- Read uncommitted
- Read committed
- Repeatable read
- Serializable

## Answer
**B.** Read committed

## Solution
Read committed only shows committed data, so there are no dirty reads. But if you read a row twice, another transaction may commit an update in between, so the two reads differ (non-repeatable read).
