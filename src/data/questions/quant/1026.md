## Question
You draw a number uniformly at random from $[0,1]$. You may redraw as many times as you like, but each redraw costs a fixed amount $c$. Your final payoff is whatever number you end up keeping. What is the optimal strategy, and what equation determines the optimal threshold $t$ at which you should stop redrawing?

## Hint
This is the same shape as the "Second Chance" dice problem: you should keep your current draw if it already beats what a fresh redraw would be worth, and redraw otherwise. The optimal threshold is the point where you're exactly indifferent between the two options — set up that equality rather than trying to guess $t$ directly.

## Answer
Stop redrawing as soon as your current draw is $\ge t$, where $t$ solves $t = \dfrac{t^2+1}{2} - c$.

## Solution

### The strategy: a threshold rule

Since every redraw is an independent fresh draw from the same $\text{Uniform}(0,1)$ distribution, the optimal strategy has a simple shape: redraw whenever your current number is below some threshold $t$, and stop once it's $\ge t$. This is exactly the same logic as the **Second Chance** dice puzzle (roll a die, optionally reroll once, get paid the final value) — there, the reroll cutoff was "reroll iff your current roll is below the unconditional mean of a fresh roll," because a fresh roll is *always* worth its mean in expectation, so it only helps to swap out values below that mean.

Here the difference is that redrawing has a cost $c$, and you can redraw indefinitely rather than just once — so the cutoff isn't simply "the mean of one fresh draw," it has to be found self-consistently.

### Finding the threshold by indifference

At the optimal threshold $t$, you must be exactly indifferent between two options:

- **Stop now**, with a draw sitting right at $t$: payoff $= t$.
- **Redraw once more** (paying cost $c$), then continue playing the same optimal policy: payoff $= -c + \mathbb{E}[\text{value of continuing with threshold } t]$.

Since the policy is stationary (you always compare against the same $t$), the continuation value is exactly:

$$\mathbb{E}[\text{continuing}] = \int_0^1 \max(x, t)\, dx$$

Here, drawing $x$: if $x \ge t$ you keep it (worth $x$); if $x < t$, by the indifference argument this branch is worth the same as being back at the threshold itself (worth $t$) — so $\max(x,t)$ captures both branches at once.

Splitting the integral where the two pieces of $\max(x,t)$ apply:

$$\int_0^1 \max(x,t)\,dx = \int_0^t t \, dx + \int_t^1 x\, dx = t^2 + \left(\frac{1}{2} - \frac{t^2}{2}\right) = \frac{t^2+1}{2}$$

So the indifference equation is:

$$t = \frac{t^2+1}{2} - c$$

This is a quadratic in $t$ (given $c$), solvable directly once a specific cost is fixed.

### Reflex to keep

**"Redraw / reroll if below a threshold" problems all reduce to an indifference equation**: set the value of stopping equal to the value of one more attempt, where the "one more attempt" term uses $\max(\text{new draw}, \text{threshold})$ to fold in the fact that the policy repeats itself. The discrete version (Second Chance, a fair die) just replaces the integral with a finite sum over outcomes, and has no cost term to worry about since the die can only be rerolled once. The continuous version with unlimited, costly redraws needs the self-consistent integral equation instead of a flat comparison to a single mean.
