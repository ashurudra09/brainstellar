## Question
Units sold: A 240 → 300, B 400 → 460, C 150 → 210. Which product grew most in % terms?

## Options
- C
- A
- B
- A and C tie

## Answer
**A.** C

## Solution
A +25%, B +15%, C +40%. Absolute growth is +60 for each, so the smallest base wins.
