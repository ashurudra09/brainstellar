## Question
If (3x+2)/((x−2)(x+3)) = A/(x−2) + B/(x+3), find A.

## Options
- −5/9
- 8/5
- 1
- 0

## Answer
**B.** 8/5

## Solution
3x+2 = A(x+3) + B(x−2). Put x = 2: 8 = 5A.
