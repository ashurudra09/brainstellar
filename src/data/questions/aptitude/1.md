## Question
Natural numbers a, b, c, d sum to 63. Maximise ab + bc + cd.

## Answer
991

## Solution
ab + bc + cd = (a + c)(b + d) − ad. Take d = 1, then choose a + c = 32 and b + d = 31: 32·31 − 1 = 991.
