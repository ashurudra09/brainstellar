## Question
Statements: All A are B. Some B are C. Which conclusion follows: 'Some A are C'?

## Options
- Does not follow
- Follows
- Follows only if C is a subset of B
- Cannot be judged

## Answer
**A.** Does not follow

## Solution
Draw A inside B, with C overlapping only the part of B outside A. Both statements hold and the conclusion fails, so it doesn't follow.
