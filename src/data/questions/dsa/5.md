## Question
T(n) = T(n/2) + n solves to:

## Options
- Θ(log n)
- Θ(n)
- Θ(n log n)
- Θ(n²)

## Answer
**B.** Θ(n)

## Solution
Unroll it: n + n/2 + n/4 + … is a geometric series that stays below 2n. So Θ(n), not n log n: there's only one subproblem per level.
