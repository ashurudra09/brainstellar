## Question
Detecting a cycle in a singly linked list in O(1) extra space:

## Options
- Floyd's slow/fast pointers
- A hash set of visited nodes
- Reversing the list
- Sorting the nodes

## Answer
**A.** Floyd's slow/fast pointers

## Solution
The fast pointer moves 2 steps and the slow one 1. If there's a cycle they must meet. A hash set also works, but needs O(n) space.
