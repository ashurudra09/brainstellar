## Question
Dijkstra's algorithm may give wrong answers when the graph has:

## Options
- Cycles
- Negative edge weights
- Zero-weight edges
- Undirected edges

## Answer
**B.** Negative edge weights

## Solution
Dijkstra fixes a vertex's distance as soon as it is the closest unvisited one, assuming no later path can be shorter. A negative edge breaks that assumption. Bellman-Ford handles negative edges.
