## Question
T(n) = T(n−1) + n solves to:

## Options
- O(n²)
- O(n log n)
- O(n)
- O(2ⁿ)

## Answer
**A.** O(n²)

## Solution
n + (n−1) + … + 1 = n(n+1)/2.
