## Question
Time complexity?

```text
for (i = 1; i <= n; i++)
    for (j = i; j <= n; j += i)
        work();
```

## Options
- O(n log n)
- O(n²)
- O(n)
- O(n√n)

## Answer
**A.** O(n log n)

## Solution
For each i the inner loop runs n/i times. Summing n/i over i = 1..n gives n·Hₙ ≈ n ln n.
