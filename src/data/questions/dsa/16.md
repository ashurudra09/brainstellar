## Question
Inorder traversal of a binary search tree gives:

## Options
- Keys in ascending order
- Keys in level order
- The root first
- Keys in descending order

## Answer
**A.** Keys in ascending order

## Solution
Left subtree (smaller), then the node, then the right subtree (larger), applied recursively, gives the keys in sorted order.
