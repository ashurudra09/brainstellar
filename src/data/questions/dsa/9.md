## Question
Worst case of quicksort with the first element as pivot occurs on:

## Options
- Random input
- Already sorted input
- All distinct keys
- Small arrays

## Answer
**B.** Already sorted input

## Solution
On sorted input the first element is the minimum, so each partition splits off just one element. Total work is n + (n−1) + … = Θ(n²).
