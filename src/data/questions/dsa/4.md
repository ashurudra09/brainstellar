## Question
Which sorting algorithm is stable?

## Options
- Quick sort
- Heap sort
- Merge sort
- Selection sort

## Answer
**C.** Merge sort

## Solution
Stable means equal keys keep their original order. Merge sort takes from the left half on ties, so it is stable. Quick, heap and selection sort swap elements across long distances and can reorder equal keys.
