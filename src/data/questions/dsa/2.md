## Question
Given the head of a singly linked list, reverse the list in place and return the new head.

## Constraints
- The number of nodes is in the range `[0, 5000]`.
- `-5000 <= Node.val <= 5000`

## Examples
`1 -> 2 -> 3 -> None` becomes `3 -> 2 -> 1 -> None`.

## Hint
You only need three pointers: the node you're processing, the node before it, and a temporary to hold "next" before you overwrite it.

## Approach
Walk the list once, and at each node flip its `.next` pointer to point backward instead of forward, carrying along a `prev` pointer that starts at `None`.

## Complexity
Time: `O(n)`. Space: `O(1)`.

## Code
```python
def reverse_list(head):
    prev = None
    while head:
        nxt = head.next
        head.next = prev
        prev = head
        head = nxt
    return prev
```

## Fun Fact
This is one of the few "trivial" interview questions that trips people up live, purely from forgetting to save `head.next` before overwriting it -- a good one to practice on a whiteboard, not just in your head.

## Solution
`prev` accumulates the reversed portion of the list as we go. Each iteration detaches the current node from the rest of the original list (by saving `nxt` first) and re-attaches it to the front of the reversed portion. When `head` becomes `None`, `prev` is the new head.
