## Question
Time complexity?

```text
for (i = 1; i < n; i *= 2)
    for (j = 0; j < i; j++)
        work();
```

## Options
- O(n)
- O(n log n)
- O(log n)
- O(n²)

## Answer
**A.** O(n)

## Solution
The inner loop runs 1 + 2 + 4 + … + n/2 times, a geometric series that sums to about n. So O(n), not n log n.
