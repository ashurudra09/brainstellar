## Question
In an election, candidate A receives $a$ votes and candidate B receives $b$ votes, with $a > b$. If the votes are counted one at a time in a uniformly random order, what is the probability that A is strictly ahead of B in the running tally after every single vote is counted (i.e., A is never tied with or behind B at any point during the count)?

## Hint
Think of the count as a lattice path: step right for a vote for A, step up for a vote for B. "A always ahead" means the path never touches the line $y = x$ after the first step. Try reflecting the "bad" paths across that line.

## Answer
$$\dfrac{a-b}{a+b}$$

## Solution
This is the classical **Bertrand ballot problem**.

### Setting up the path picture
Represent a counting order as a lattice path from $(0,0)$ to $(a,b)$: each vote for A is a step right, each vote for B is a step up. Every one of the $\binom{a+b}{b}$ orderings corresponds to exactly one such path, uniformly at random.

"A is always strictly ahead after every vote is counted" means the path stays strictly below the diagonal line $y = x$ for its entire length after the first step (touching or crossing $y=x$ would mean a tie or B ahead).

### First step must go to A
If the very first vote counted is for B, then immediately B leads $1$-$0$, so A can never have been "always ahead." Hence the first step must be a step right (a vote for A), which happens with probability $a/(a+b)$.

### Reflection principle on the rest
Condition on the first vote being for A, so the path starts at $(1,0)$ and needs to reach $(a,b)$ without ever touching the diagonal $y=x$ again.

Count the "bad" paths from $(1,0)$ to $(a,b)$ that touch $y=x$ at some point. For any such bad path, reflect the portion of the path from $(1,0)$ up to its *first* touch of the diagonal across that diagonal. This maps the start point $(1,0)$ to $(0,1)$, and the rest of the path is unchanged, giving a path from $(0,1)$ to $(a,b)$. This reflection is a bijection between bad paths starting at $(1,0)$ and *all* paths from $(0,1)$ to $(a,b)$.

- Number of all paths from $(1,0)$ to $(a,b)$: $\binom{a+b-1}{b}$
- Number of paths from $(0,1)$ to $(a,b)$ (all of which are "bad" by the bijection above): $\binom{a+b-1}{b-1}$

So the number of *good* paths from $(1,0)$ to $(a,b)$ is
$$\binom{a+b-1}{b} - \binom{a+b-1}{b-1}.$$

### Putting it together
$$
P(\text{A always ahead}) = \frac{a}{a+b}\cdot\frac{\binom{a+b-1}{b} - \binom{a+b-1}{b-1}}{\binom{a+b-1}{b}}
$$

Using $\binom{a+b-1}{b-1} = \binom{a+b-1}{b}\cdot\dfrac{b}{a}$, this simplifies to

$$
P = \frac{a}{a+b}\left(1 - \frac{b}{a}\right) = \frac{a-b}{a+b}.
$$

### Sanity checks
- If $a = b$: probability is $0$ — a tie must occur at the very end, so A can't be ahead the *whole* way through.
- If $b = 0$: probability is $1$ — A is trivially always ahead.
- If $a = b+1$ (closest possible race): probability is $\dfrac{1}{2b+1}$, small but nonzero.
