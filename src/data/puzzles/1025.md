## Question
There are $P$ cards, each either face up or face down. Let $k$ be the number of cards currently face-up. Flip the $k$-th card (in some fixed order), and repeat.

1. Prove that, starting from **any** configuration, this process always terminates (reaches all cards face-down, at which point $k=0$ and there is no card to flip).
2. Find the expected number of steps to termination, starting from a **uniformly random** configuration of $P$ cards.

## Hint
For part 1: the process is deterministic on a finite state space, so it either halts or cycles — rule out cycles by strong induction on $P$, splitting on whether the last card starts up or down.

For part 2: split on the last card again. If it starts down, you get the $(P-1)$-card problem for free. If it starts up, try complementing every bit and reversing the card order on the rest — see what rule that turns the dynamics into.

## Answer
1. Yes, it always terminates.
2. $E_P = \dfrac{P(P+1)}{4}$.

## Solution

### Part 1: Termination, by strong induction on $P$

**Base case** ($P=1$): from face-down, the process is already terminal (0 steps). From face-up, $k=1$, flip the one card, done in 1 step. Either way it terminates.

**Inductive step.** Assume every configuration of $P-1$ cards terminates in finitely many steps. Consider a configuration $x = (x_1, \ldots, x_P)$ of $P$ cards.

**Case $x_P = 0$ (last card down).** The total up-count is $k = (\text{up-count of the first } P-1 \text{ cards})$, since the last card contributes $0$. This never exceeds $P-1$, so card $P$ is *never* selected — every flip targets one of the first $P-1$ cards, and the rule applied to them (flip the card whose index equals the current up-count) is exactly the standard $(P-1)$-card process running on the prefix, with card $P$ frozen at $0$. By the induction hypothesis, this prefix process terminates in finitely many steps, so the whole configuration does too.

**Case $x_P = 1$ (last card up).** Let $u$ denote the up-count of the first $P-1$ cards at any point while $x_P$ remains $1$; the total up-count is $u+1$. As long as $u < P-1$, we have $k = u+1 \le P-1$, so the flip always lands on a prefix card — specifically, card number $u+1$ (one more than the prefix's own up-count). Call this the **shifted rule**.

*Claim: the shifted rule on the prefix is exactly the standard rule on a transformed copy of the prefix.* Define $y_i = 1 - x_i$ (complement every bit) and $z_i = y_{P-i}$ for $i = 1, \ldots, P-1$ (reverse the order). If the prefix $x$ has up-count $u$, then $y$ has up-count $(P-1) - u$, and since reversing doesn't change a count, $z$ has up-count $v = (P-1) - u$ as well. Flipping $x_{u+1}$ is the same physical bit as flipping $y_{u+1}$, which (by the reversal $z_i = y_{P-i}$, i.e. $y_{u+1} = z_{P-1-u} = z_v$) is the same bit as flipping $z_v$ — and $v$ is exactly $z$'s own up-count. So flipping $x_{u+1}$ under the shifted rule corresponds, step for step, to flipping $z_v$ under the **standard** rule.

The handoff point $u = P-1$ (prefix all up) corresponds to $v = 0$ (i.e. $z$ all down) — exactly the standard game's terminal condition. So the shifted process on $x$'s prefix terminates (reaches "all up") in finitely many steps if and only if the standard $(P-1)$-card process on $z$ terminates — which it does, by the induction hypothesis.

Once the prefix reaches all-up while $x_P = 1$, the total up-count becomes $P$, so card $P$ flips (down), landing us in the $x_P = 0$ case with an all-up prefix — which terminates in finitely many further steps by the case above.

Either way, the $P$-card process terminates. $\blacksquare$

### Part 2: Expected number of steps, $E_P$

Let $E_P$ denote the expected number of steps to termination from a uniformly random configuration of $P$ cards ($E_0 = 0$).

**Split on the last card**, each case occurring with probability $1/2$:

**If $x_P = 0$:** by the Part 1 argument, the dynamics exactly mirror the standard $(P-1)$-card process on a uniformly random prefix. Expected steps in this branch: $E_{P-1}$.

**If $x_P = 1$:** by the bijection above, the number of steps for the prefix to reach "all up" under the shifted rule equals the number of steps for the standard $(P-1)$-process on $z$ (the complemented, reversed prefix) to terminate. Since the original prefix is uniform, so is $z$ (complementing and reversing are bijections), so this takes $E_{P-1}$ steps in expectation. Then **1 more step** flips card $P$ down. The prefix is now all up, and card $P$ is down — the case above shows this then runs as a standard $(P-1)$-process starting specifically from **all cards up**.

Let $M_n$ be the (deterministic) number of steps for the standard $n$-card process starting from all cards up. From all-up, $k=n$, so the top card flips down, leaving "$n-1$ cards up, one down" — which by the $x_P=0$ argument runs as the standard $(n-1)$-process on an all-up prefix. So $M_n = 1 + M_{n-1}$, with $M_1 = 1$ (single up card flips once). Hence $M_n = n$.

So, in the $x_P=1$ branch: expected steps $= E_{P-1} + 1 + M_{P-1} = E_{P-1} + 1 + (P-1) = E_{P-1} + P$.

**Combining both branches:**

$$E_P = \frac{1}{2}E_{P-1} + \frac{1}{2}\left(E_{P-1} + P\right) = E_{P-1} + \frac{P}{2}$$

Solving this recurrence with $E_0 = 0$:

$$E_P = \sum_{i=1}^{P} \frac{i}{2} = \frac{1}{2}\cdot\frac{P(P+1)}{2} = \frac{P(P+1)}{4}$$

Checking against small cases: $E_1 = 1/2$, $E_2 = 3/2$, $E_3 = 3$, $E_4 = 5$, $E_5 = 15/2$ — all match direct enumeration.

### Reflexes to keep

- **Termination on a finite, deterministic state space:** it must halt or cycle — ruling out cycles via induction on a natural sub-structure (here, the last card) is the standard move.
- **A "shifted" version of a familiar rule is often the familiar rule in disguise.** Here, complementing every bit and reversing the order turned the shifted rule back into the standard rule on a bijectively-transformed (and still uniformly random) state — which is what makes the expectation solvable in closed form rather than needing brute-force enumeration.
